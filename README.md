# 🧠 Repositório de Algoritmos e Estruturas de Dados

Bem-vindo ao meu laboratório de algoritmos! Este repositório foi criado para consolidar fundamentos de Ciência da Computação, lógica de programação e engenharia de software através da implementação de estruturas de dados e algoritmos clássicos em múltiplas linguagens (**C, C++, C#, Java e Python**).

---

## 📂 Estrutura do Repositório

O projeto está organizado da seguinte forma:

```text
algoritmos/
├── c/                      # Foco em ponteiros, alocação dinâmica e baixo nível
├── cpp/                    # Foco em STL, orientação a objetos e templates
├── csharp/                 # Foco em ecossistema .NET e tipagem moderna
├── java/                   # Foco em OOP robusta e coleções
└── python/                 # Foco em expressividade e programação dinâmica
```

---

## 🚀 Linguagens e Tecnologias Utilizadas

* **C:** Implementações focadas no gerenciamento manual de memória (`malloc`/`free`) e estruturas lineares.
* **C++:** Uso da *Standard Template Library (STL)* e algoritmos eficientes de grafos.
* **C#:** Estruturas de dados utilizando os recursos modernos da linguagem e do .NET.
* **Java:** Abordagem voltada a orientação a objetos, encapsulamento e coleções.
* **Python:** Scripts voltados para legibilidade, matemática e otimização (programação dinâmica).

---

## 🛠️ Como Executar os Exemplos

Cada subpasta possui seus próprios códigos. Aqui estão exemplos rápidos de como compilar ou executar cada linguagem:

### 🔹 Em C
```bash
cd c/data_structures
gcc linked_list.c -o linked_list
./linked_list
```

### 🔹 Em C++
```bash
cd cpp/data_structures
g++ bst.cpp -o bst
./bst
```

### 🔹 Em C#
```bash
cd csharp/data_structures
dotnet run
```

### 🔹 Em Java
```bash
cd java/data_structures
javac CustomQueue.java
java CustomQueue
```

### 🔹 Em Python
```bash
cd python/dynamic_programming
python knapsack.py
```
