# 🧠 Repositório de Algoritmos e Estruturas de Dados

Bem-vindo ao meu laboratório de algoritmos! Este repositório foi criado para consolidar fundamentos de Ciência da Computação, lógica de programação e engenharia de software através da implementação de estruturas de dados e algoritmos clássicos em múltiplas linguagens (**C, C++, C#, Java e Python**).

---

O projeto está organizado da seguinte forma:

```text
algoritmos/

├── java/                   # Foco em OOP robusta e coleções
