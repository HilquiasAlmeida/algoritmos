# ☕ Módulo Java - Estruturas de Dados

Bem-vindo à seção de **Java** deste repositório. O foco aqui é explorar os conceitos de Programação Orientada a Objetos (OOP), tipagem estática e o gerenciamento de coleções e estruturas lineares.

---

## 📂 Estrutura de Pastas e Conteúdo

```text
language_java/
└── data_structures/
    └── custom_queue.java    # Implementação personalizada de uma Fila (Queue FIFO)
```
## 🚀 Conceitos Principais
Princípio FIFO (First In, First Out): O primeiro elemento a entrar na fila é o primeiro a ser removido.

Orientação a Objetos (OOP): Uso de classes, encapsulamento e tipos genéricos (Generics).

Manipulação de Listas Ligadas: Implementação da lógica interna utilizando LinkedList para gerenciar os elementos com eficiência.

## 🛠️ Como Compilar e Executar
Certifique-se de ter o JDK (Java Development Kit) instalado em sua máquina.

##  1. Acesse a pasta onde está o arquivo:
```
Bash
cd data_structures
```
##  2. Compile o arquivo fonte Java:
```
Bash
javac custom_queue.java
```

##  3.Execute a classe compilada:
```
  Bash
  java custom_queue
```
