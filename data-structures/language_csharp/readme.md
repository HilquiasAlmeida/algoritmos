# 🔷 Módulo C# - Estruturas de Dados

Bem-vindo à seção de **C#** e ecossistema **.NET** deste repositório. O foco aqui é explorar tipagem forte, programação orientada a objetos moderna, Genéricos (*Generics*) e estruturas de dados eficientes.

---

## 📂 Estrutura de Pastas e Conteúdo

```text
language_csharp/
└── data_structures/
    └── custom_stack.cs    # Implementação personalizada de uma Pilha (Stack LIFO)
```

## 🚀 Conceitos Principais
Princípio LIFO (Last In, First Out): O último elemento a entrar na pilha é o primeiro a ser removido.

Tipos Genéricos (Generics): Criação de estruturas reutilizáveis para qualquer tipo de dado (T).

Encapsulamento e Segurança: Proteção do estado interno da estrutura e tratamento de exceções (como pilha vazia).

## 🛠️ Como Compilar e Executar
Certifique-se de ter o .NET SDK instalado em sua máquina.

### 1.Acesse a pasta onde está o arquivo:
```
Bash
cd data_structures
```

### 2.Se estiver em um projeto .NET configurado, utilize:
```
Bash
dotnet run
```

### 3.Ou compile diretamente o arquivo avulso via compilador do C# (csc):
```
Bash
csc custom_stack.cs
```
