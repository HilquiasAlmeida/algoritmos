# 💻 Algoritmos e Estruturas em C

Esta pasta contém implementações em **C**, focadas em baixo nível, gerenciamento manual de memória (`malloc`/`free`) e manipulação de ponteiros.

---

## 📂 Subpastas
* **`data_structures/`**: Estruturas lineares construídas do zero (ex: Lista Encadeada).
* **`sorting/`**: Algoritmos clássicos de ordenação (ex: Bubble Sort).

---

## 🛠️ Como Compilar e Executar

Certifique-se de ter o compilador GCC instalado e execute no terminal:

### Para a Lista Encadeada:
```bash
cd data_structures
gcc linked_list.c -o linked_list
./linked_list
