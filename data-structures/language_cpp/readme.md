# 🌲 Módulo C++ - Estruturas de Dados e Hierarquias

Bem-vindo à seção de **C++** deste repositório. O foco aqui é explorar o paradigma de Orientação a Objetos, o gerenciamento de memória com ponteiros e a implementação de estruturas de dados hierárquicas avançadas.

---

## 📂 Estrutura de Pastas e Conteúdo

```text
language_cpp/
└── structures/
    └── bst.cpp           # Árvore Binária de Busca (Binary Search Tree)
```

## 🚀 Conceitos Principais
* Árvore Binária de Busca (BST): Estrutura de dados hierárquica onde cada nó possui no máximo dois filhos, organizados de forma que os valores menores fiquem à esquerda e os maiores à direita.

* Ponteiros e Alocação: Uso intensivo de ponteiros (Node*) e alocação dinâmica para conectar os nós na memória de forma eficiente.

* Percurso em Ordem (Inorder Traversal): Algoritmo para visitar e exibir os elementos da árvore de forma ordenada.

## 🛠️ Como Compilar e Executar
Certifique-se de ter o compilador G++ (com suporte ao padrão C++11 ou superior) instalado em sua máquina.

### 1.Acesse a pasta onde está o arquivo:
```
Bash
cd structures
```
### 2.Compile o código com o G++:
```
Bash
g++ bst.cpp -o bst -std=c++11
```
### 3.Execute o programa gerado:

* No Linux / macOS:
```
Bash
./bst
```
* No Windows (PowerShell / CMD):
```
Bash
.\bst.exe
```
