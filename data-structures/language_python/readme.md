# 🐍 Programação Dinâmica em Python

Esta pasta contém scripts em **Python** focados em legibilidade de código, resolução de problemas matemáticos complexos e otimização de algoritmos através de **Programação Dinâmica**.

---

## 📂 Estrutura de Pastas e Conteúdo

```text
language_python/
└── dynamic_programming/
    └── knapsack.py       # Solução clássica para o Problema da Mochila (0/1 Knapsack)
```
## 🚀 Conceitos Principais

Programação Dinâmica (DP): Otimização de problemas complexos dividindo-os em subproblemas menores e reutilizando seus 
resultados (Memoization / Tabulation).

---

## Problema da Mochila (Knapsack Problem):
Algoritmo clássico de otimização combinatória aplicado à tomada de decisões com restrição de capacidade.

---
Produtividade e Legibilidade: Código limpo, expressivo e de fácil manutenção.

## 🛠️ Como Executar
Certifique-se de ter o Python 3 instalado em seu computador.

Acesse a pasta:

### Bash
```
cd dynamic_programming
Execute o script diretamente pelo terminal:
```
### Bash
```
python knapsack.py
```
(Ou python3 knapsack.py dependendo da sua instalação).
