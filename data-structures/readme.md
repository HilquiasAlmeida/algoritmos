# 📦 Data Structures & Algorithms Lab

Bem-vindo à seção de estruturas de dados e algoritmos! Esta pasta centraliza implementações divididas por linguagens de programação, focando em conceitos fundamentais, lógica de baixo nível e algoritmos clássicos.

---

## 📂 Estrutura de Pastas

A organização interna desta pasta segue o layout abaixo:

```text
data-structures/
├── language_cpp/
│   └── structures/
│       └── bst.cpp            # Árvore Binária de Busca (Binary Search Tree)
│
├── language_csharp/
│   └── data_structures/
│       └── custom_stack.cs    # Implementação de Pilha customizada em C#
│
├── language_java/
│   └── data_structures/
│       └── custom_queue.java  # Implementação de Fila customizada em Java
│
├── language_python/
│   └── dynamic_programming/
│       └── knapsack.py        # Problema da Mochila (Programação Dinâmica)
│
└── languange_c/
    └── sorting/
        └── bubble_sort.c      # Algoritmo de Ordenação Bubble Sort em C
```

🚀 Tecnologias e Implementações

* **C (`languange_c/`):** Focado em ordenação e lógica procedural de baixo nível.
* **C++ (`language_cpp/`):** Focado em estruturas de dados hierárquicas e ponteiros (BST).
* **C# (`language_csharp/`):** Focado no ecossistema .NET com estruturas lineares (Pilhas).
* **Java (`language_java/`):** Focado em orientação a objetos e coleções (Filas).
* **Python (`language_python/`):** Focado em algoritmos de otimização e programação dinâmica.
